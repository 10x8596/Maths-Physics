# Chaos Equations Visualizer

This project visualizes chaotic patterns generated by dynamic equations. It uses SFML for graphics rendering and allows users to explore different equations and their resulting chaotic behavior.

## Introduction

This program generates beautiful and complex patterns by iteratively applying dynamic equations to points on the screen.  These equations, often involving trigonometric functions, polynomials, or other mathematical expressions, can produce chaotic behavior, sometimes leading to visually stunning results. The program allows users to experiment with different equations and their parameters, observing how these changes affect the generated patterns.

## Features

*   **Dynamic Equations:**  The program supports multiple predefined equations, and it's easy to add more.
*   **Random Equation Selection:** Pressing the spacebar switches to a new randomly chosen equation.
*   **Adjustable Parameters:** Each equation has parameters that are randomly generated when the equation is selected.
*   **Colorized Points:** Points are assigned random colors.
*   **Efficient Rendering:** Uses `sf::VertexArray` for efficient rendering of point trails.
*   **Equation Display:** Displays the current equation index (or coefficients if configured).

## Building

1.  **SFML:** Ensure you have SFML (version 3.0 or later) installed on your system. Download it from the official SFML website: [https://www.sfml-dev.org/](https://www.sfml-dev.org/)
2.  **Compiler:** You'll need a C++ compiler (like g++, Visual Studio, or Clang).
3.  **Project Files:** Clone or download the project files.
4.  **Compilation:**
    *   **g++ (Example):**
        run make in terminal
        (Adjust the SFML include and library paths in makefile to match your SFML installation.)
    *   **Other IDEs:**  Configure your IDE (Visual Studio, Code::Blocks, etc.) to include the SFML headers and libraries.  Consult the SFML documentation for help with IDE setup.

## Usage

1.  **Executable:** Run the compiled executable (`main.exe` on Windows, `./main` on Linux/macOS).
2.  **Window:** A window will appear displaying the chaotic patterns.

## Controls

*   **Spacebar:** Press the spacebar to generate a new random equation and reset the simulation.

## Equations

The program uses a set of predefined equations to generate the chaotic patterns.  The specific equations used can be found in the `main.cpp` file.  New equations can be added by defining new functions with the correct signature and adding them to the `equations` array.

## Dependencies

*   **SFML:**  A library for graphics rendering, window management, and input handling.
